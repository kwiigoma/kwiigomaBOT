# kwiigonaBOT v9.6

今回の更新は **GomaLog と くぃチューバーだけ** を修正しています。

## GomaLog
- 連続ログインは日本時間の暦日で判定。
- 前日から1日でも空いた場合、次回ログインは1日目から再開。
- 同じ日の2回目の受け取りは不可。

## くぃチューバー
YouTubeの実際の仕組みを参考に、単純な「投稿すれば再生される」方式から変更。

- インプレッション
- CTR
- 視聴維持率
- 視聴者満足度
- トピックの需要と競争
- チャンネル規模
- 企画・編集・サムネ・話術のスキル
- 投稿間隔による連続投稿
- 長尺の再生時間
- Shortsの90日間視聴回数
- 収益化条件
- 収益化後のみ広告収益

をシミュレーションします。

収益化条件は現在のYouTubeの広告収益分配の基準を参考に、登録者1,000人＋「過去12か月の対象長尺4,000時間」または「過去90日間の対象Shorts 1,000万回」を使用しています。実際のYouTubeでは条件を満たしただけで自動的に収益化されるわけではなく、審査があります。
